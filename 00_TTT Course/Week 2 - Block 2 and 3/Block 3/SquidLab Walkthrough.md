### 4. Environment Setup (WSL)

1.  **Import the Alpine image** – follow the “Issue Alpine.tar / WSL import steps” in the guide.
    
2.  **Launch the distro**: `wsl -d Alpine`. Verify the prompt (`root@…:#`).
    
3.  **Record baseline host facts** (required before any hunting):
    
    ```bash
    hostname               # host identity
    whoami                 # current user
    pwd                    # working directory
    ps aux                 # process list
    netstat -tuln         # listening sockets
    ```
    
    Save the output to a file (e.g., `/tmp/initial_state.txt`).
    

These steps satisfy the “record host identity, user, working path, and process list” requirement in the lesson plan [2].

* * *

### 5. Network Discovery

| Command | Purpose |
| --- | --- |
| `nmap -sn 192.168.135.0/24` | Ping‑scan the entire lab LAN to confirm the target is up. |
| `nmap -Pn -sV -p- 192.168.135.1` | Full TCP port scan with service version detection on the primary host. |

Both commands are explicitly listed in the lesson plan [2].

* * *

### 6. Retrieve the Staging Tree

```bash
curl http://192.168.135.1:8000/
```

_Result:_ “Port 8000/tcp is a Python HTTP staging tree (/opt/squid‑stage).” [2]

* * *

### 7. Prepare the Sliver Operator Config

1.  **Download the config file** (the same URL used above or the provided file share).
    
2.  **Edit the file** – replace the placeholder IP with `192.168.135.1`.
    

```bash
sed -i 's/PLACEHOLDER_IP/192.168.135.1/' modified-operator.cfg
```

* * *

### 8. Import the Config & Start Sliver

```bash
sliver-client import <modified-operator.cfg>
sliver-client          # start the client
```

The import loads a multiplayer configuration; the client then shows the usual Sliver objects (sessions, beacons, jobs, operators) [2].

* * *

### 9. Survey & Report (In‑Scope Activities)

```bash
sliver-client sessions
sliver-client beacons
sliver-client jobs
sliver-client operators
sliver-client info
```

_Instructor script_: “Import as an operator. Answer the 5 Ws. Name an effect. **Do not pull the trigger**.” [2]
**Scope clarification** – Survey and report are **in‑scope**; killing listeners or implants is **recommendation‑only** [2].

* * *

### 10. Collect Artifacts

```bash
sliver-client collect   # or manually copy relevant output files
```

Gather the following for grading:

*   Initial host‑state file (`/tmp/initial_state.txt`)
    
*   Nmap scan results
    
*   Curl output (staging tree listing)
    
*   Modified Sliver config
    
*   Sliver session/beacon/job listings
    
*   Final report generated by the student
    

* * *

### 11. Clean‑up

*   Stop the Sliver client (`Ctrl‑C` or `sliver-client exit`).
    
*   Shut down the Alpine WSL instance (`wsl --terminate Alpine`).
