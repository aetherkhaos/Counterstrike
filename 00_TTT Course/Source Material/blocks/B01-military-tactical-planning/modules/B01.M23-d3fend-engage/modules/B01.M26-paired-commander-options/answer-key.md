# Paired Commander Options — Instructor Answer Key

## Objective and starting context

Each ATT&CK row needs a D3 option and an ENGAGE option with goal, expected effect, and risk. Source: the student-deck option table and the worked rows on the synthesis deck. Where the engage cell is blank, the acceptable shape below is taken from those worked rows and from the parent lesson's minimum option set.

## Expected product

At least three paired rows. Blank engage cells on the five-log table are the students' work.

## Acceptable answers

Worked rows already printed on the synthesis deck, for teaching the shape:

- T1078 Valid Accounts, with D3 script analysis and EAC0005 lures. Goal Expose. Effect: a high-fidelity alert. Risk: very low. Tactical-task cells on that row are still the students' (see the synthesis key).
- T1059 Command and Scripting Interpreter, with script analysis and EAC0014 software manipulation. Goal Affect. Effect: degrade the workflow. Risk: low.
- T1021 Remote Services, with network isolation and EAC0020 isolation. Goal Elicit. Effect: capture TTPs. Risk: moderate because activity can spill.

For the five-log table, the deck starts some defend cells and leaves engage blank. Accept any EAC the team can open on the ENGAGE matrix when the goal, effect, and risk are filled. A strong engage choice for the email or credential path is EAC0005. A strong engage choice for PowerShell is EAC0014. Do not accept a goal of "defend" ; the three goals are Expose, Affect, and Elicit.

The deck's later engage starters include EAC0005, EAC0007, and EAC0016 on some rows. Treat EAC0007 as acceptable only if the team can show it on the matrix. If they cannot, they replace it.

## Grading checkpoints

- Accept: both options, a goal, an effect, and a risk that is not automatically "extremely high."
- Do not accept: a D3 code pasted with an empty engage cell.
