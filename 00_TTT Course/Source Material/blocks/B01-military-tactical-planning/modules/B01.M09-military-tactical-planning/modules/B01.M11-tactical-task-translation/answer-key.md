# Tactical-Task Translation — Instructor Answer Key

## Objective and starting context

Teams sort tactical tasks into those that translate to cyberspace, those that translate with work, and those that do not. Source: parent content guide slide 6 and the student-deck note that the point is not to shoehorn every task.

## Expected product

A marked task sheet and a back-brief. Keep the sheet. A later hour maps frameworks onto the same verdicts.

## Acceptable answers

- Clean translations the lecture names: reconnoiter, disrupt, destroy.
- Translations that take work: seize, control.
- A reasoned "does not apply" is a full-credit verdict.
- Grade the argument, not agreement on one verb.

## Grading checkpoints

- Accept: each cited task has a translate / modify / does-not-apply label and a reason.
- Do not accept: a silent copy of the task list, or a rule that every verb must have a cyber meaning.
