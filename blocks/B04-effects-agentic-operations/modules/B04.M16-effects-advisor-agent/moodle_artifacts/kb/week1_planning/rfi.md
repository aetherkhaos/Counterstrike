# Requests for information (Week 1 extract)

When evidence is insufficient to choose an effect, write an RFI rather than
forcing deny/degrade. `reconnoiter` (canary, lure, or additional collection)
is how an automated advisor closes an RFI without executing a damaging effect.

Record the canary or collection path in the rollback plan so the team can
remove it when the RFI is answered.
