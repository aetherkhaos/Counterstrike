Hack The Box content should be accessed through your PCTE account.

First, log into [https://dash.ent1.pcte.mil/app/app](https://dash.ent1.pcte.mil/app/app)

You should see a page like this:
![[Pasted image 20261013123312.png]]
Next, click on the Apps icon in the bottom right (circled above)

select "Universal Content Catalogue"
![[Pasted image 20261013123337.png]]
select Search
![[Pasted image 20261013123353.png]]
Filter Providers to "Hack the Box"
![[Pasted image 20261013123413.png]]
Enter the Module name into the search box:
![[Pasted image 20261013123430.png]]
Select "Enroll Now"
![[Pasted image 20261013123445.png]]
The Enroll Now button will change to say Launch, select this button:
![[Pasted image 20261013123500.png]]
Select "Begin Course"
![[Pasted image 20261013123519.png]]
You will likely see a message that says to disable popup blockers.  This is a lie, just click relaunch or wait several minutes.
![[Pasted image 20261013123534.png]]
Eventually you will be redirected to the Hack the Box Academy Module.  Follow Homework instructions on the course page.  You are normally not assigned an entire module.
