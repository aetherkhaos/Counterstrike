# Lab L4.3a - Instructor Setup Notes (Instructor Only)

Classroom delivery on team DGX Spark. Students enable n8n in-lab. CTI is instructor-hosted.

## Before class

1. Copy CTI from the course repo to the instructor host:

   ```bash
   rsync -a --delete environments/dgx_spark_stack/cti/ /opt/stack/cti/
   cd /opt/stack/cti
   cp env.example .env
   ```

   Set `BASE_DOMAIN` and `LITELLM_API_KEY` (match `/opt/stack/spark/.env`). Leave `CTI_API_KEY=cso-cti-k9m2p7x4q1` as copied from `env.example`. Traefik + Spark LiteLLM must already be up.

   ```bash
   docker compose up -d --build
   curl -sS "https://cti.${BASE_DOMAIN}/api/v1/ip/198.51.100.44" \
     -H "Authorization: Bearer cso-cti-k9m2p7x4q1"
   ```

   Expect `200` with score `88` / `malicious`. `summary` may vary. `8.8.8.8` → `404`. `203.0.113.250` → `500`.

2. Upload Moodle package:
   - `moodle_artifacts/auth_syslog.txt` (this lab)
   - L4.3b logs: `clean_malicious.log`, `ambiguous.log`, `intel_fail_trigger.log`

3. Publish to the class:
   - Team n8n/LiteLLM URLs (`https://n8n.<team-domain>`, `https://litellm.<team-domain>/v1`)
   - LiteLLM master key (team-shared credential)
   - Local aliases: secondary (IP extract), primary (triage)
   - Cloud frontier model id (for L4.3b branch B; name only, no vendor)
   - `https://cti.<BASE_DOMAIN>` (students use key `cso-cti-k9m2p7x4q1` from the guide)

## Part 0 watch-outs

- One teammate becomes n8n **owner** (first user). Others need invites. Do not share the owner login for graded work.
- Persist `N8N_ENCRYPTION_KEY`. Changing it invalidates stored credentials in `vols/n8n`.
- Students copy syslog to `~/stack/vols/n8n/lab_data/` → container `/home/node/.n8n/lab_data/`.
- If Traefik has no `n8n` cert yet, wait for ACME; students must already trust the class CA from L1.7b.
