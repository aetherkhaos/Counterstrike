# CAD Mini-Build

This Module was previously an embedded exercise in [B01.M28 MITRE D3FEND CAD](../B01.M28-mitre-d3fend-cad/content-guide.md). Complete it in sequence immediately after that lecture.

### Slide 13: Mini-Build Exercise

- Each team graphs the intrusion from the Block 3 Navigator lab
- Minimum required nodes:
  - 1 Agent (the adversary unit)
  - 2 Attacks (from your Navigator layer)
  - 1 Artifact
  - 1 Condition
  - 1 Countermeasure (from D3FEND)
- Minimum required edges: enough to make the graph a story, not a list

**Instructor Notes:**

- **Image Prompt:** No image required for this slide.
- **Say:** "Your team from Block 3 is still together. You already have the ATT&CK layer. Now turn it into a CAD graph with the minimum node set on this slide. Focus on provenance — every artifact has a source and an effect."
- **Show:** The minimum-node checklist; leave it visible during the exercise.
- **Do:** Timebox: **30 minutes** build + **3 minutes per team** to back-brief. Export the JSON and retain it for B01.M36.
