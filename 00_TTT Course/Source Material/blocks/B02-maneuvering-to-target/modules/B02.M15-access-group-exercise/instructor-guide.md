# Access Group Exercise — Instructor Guide

## Objective and context

Facilitation SoT for the generated lesson plan. Command-complete walkthroughs stay in the answer key. This Module is not on the hourly schedule. Offer it only to a team that finishes B02.M16 with time left. Teams complete HTB Academy Attacking Common Applications Skills Assessment II and can explain the evidence path.

## Instructor resources and pre-class

- Classroom projector and screen; whiteboard for the opening contract
- Confirm HTB Academy access and that Skills Assessment II can spawn
- Live walkthrough in [`answer-key.md`](./answer-key.md)
- Do not project flags, tokens, or answer-key values

## Student resources

- Student brief in this Module folder
- HTB Academy Attacking Common Applications course and spawned Skills Assessment II target
- No extra kit beyond what the student-facing file already lists

## Dual opening

### Option 1 (Interactive / Whiteboard / Kinesthetic)

- **Say:** "You are not hunting a remembered IP. Spawn Skills Assessment II, confirm the live target, and keep an evidence path another operator could follow."
- **Do:** Put the HTB tasking on the board. Keep the answer key closed unless a team is stuck.
- **Ask (Q):** What must the team turn in besides HTB answers?
- **Expected Response (A):** A short path summary, supporting evidence for each answer, and the most important lesson from the assessment.
