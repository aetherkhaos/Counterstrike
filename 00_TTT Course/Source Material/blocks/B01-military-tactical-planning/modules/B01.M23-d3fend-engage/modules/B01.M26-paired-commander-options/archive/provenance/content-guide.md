# Paired Commander Options

This Module was previously an embedded exercise in [B01.M23 MITRE D3FEND and ENGAGE](../B01.M23-d3fend-engage/content-guide.md). Complete it in sequence immediately after that lecture.

### Slide 12: Mapping ENGAGE into an Option Set

- For each technique on the Block 3 ATT&CK Navigator layer:
  - Identify one **D3FEND** (D3) option and one **ENGAGE** (EAC) option
  - For each option state: goal (Expose/Affect/Elicit), expected effect on CG/CV, risk, authority required
  - This is the **bare minimum** set you bring to the commander — anything less is incomplete
- Outputs extend the B01.M19 Navigator product and feed the B01.M28 CAD graph

**Instructor Notes:**

- **Image Prompt:** A two-column worksheet template. Left column labeled "ATT&CK Technique" with empty rows. Middle column labeled "D3 Option" with empty rows. Right column labeled "EAC Option" with empty rows. Bottom row labeled "Expected effect / Risk / Authority".
- **Say:** "The deliverable out of this block is a paired set — a D3 option and an EAC option — for each technique you mapped in Block 3. Think of it as the minimum viable option sheet. The commander may pick neither, but they will always be able to see *both* the harden-side and the engage-side move."
- **Show:** The worksheet template; hand out as a printable.
- **Do:** Reunite the Block 3 teams. Timebox: **30 minutes** to produce the paired option sheet for at least three of their Navigator techniques. Back-brief **one pairing per team**.
