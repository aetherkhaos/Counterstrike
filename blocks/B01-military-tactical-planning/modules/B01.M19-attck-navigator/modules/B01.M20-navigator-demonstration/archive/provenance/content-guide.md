# Navigator Demonstration

This Module was previously an embedded exercise in [B01.M19 MITRE ATT&CK and Navigator](../B01.M19-attck-navigator/content-guide.md). Complete it in sequence immediately after that lecture.

### Slide 8: Demo — ATT&CK Navigator

- ATT&CK Navigator is the canonical tool for visualizing observed TTPs
- Build a layer per intrusion; overlay layers to see overlaps across actors
- Export layers for briefs and for hand-off to intel or defenders

**Instructor Notes:**

- **Image Prompt:** No image required for this slide.
- **Say:** "The Navigator is how we visualize an intrusion. I am going to build a layer live — you should have this tool open on your own workstation too."
- **Show:** Live-open https://mitre-attack.github.io/attack-navigator/. Create a new layer. Color in 6-8 techniques that map to the FSB Center 18 example from Block 2.
- **Do:** Have each student create their own Navigator layer for the APT their team was assigned in Block 1. Timebox: **20 minutes**.
