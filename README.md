# Trainer content review

This project tracks content reviews for `cso-trainer-cohort-26c`.
The course source of truth stays in `counterstrike-operations-development/counterstrike-ops-course-content`.

Board: https://gitlab.cso.ops/cso-trainer-cohort-26c/trainer-content-review/-/boards

Direct Developers branch here and open a merge request.
Direct Reporters comment on their work item and attach a rendered file.

Register at https://gitlab.cso.ops/users/sign_up.
Then open https://gitlab.cso.ops/cso-trainer-cohort-26c and choose Request access.

## On your own system

Run `bash setup-opencode.sh` once. It installs OpenCode on this machine, points
it at your team Spark, and asks for your tokens. Open this repository in
OpenCode. `AGENTS.md` is how that session works the tickets assigned to you.
