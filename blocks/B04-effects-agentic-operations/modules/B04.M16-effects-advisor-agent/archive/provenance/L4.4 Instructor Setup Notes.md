## Part 0 watch-outs

- Do not change the team's existing chat-model GPU util by default. `vllm-embed` at `~0.06` is the only new GPU share.
- If a team already bound host `8004` or `8000`, have them pick free loopback ports (`ss -tulpn`) and keep n8n on `http://chroma:8000` (container port) regardless of host mapping.
- LiteLLM must route `embed` to `http://vllm-embed:8000/v1` (or their service name). Recreate `litellm-gateway` after editing `litellm-config.yaml`.
- Chroma stays on Docker network `web`. n8n uses `http://chroma:8000`; host scripts use `http://127.0.0.1:${CHROMA_PORT:-8000}`.
- Traefik certresolver on team boxes is `labca` **if** they followed L1.7b. Confirm against their Traefik labels before debugging TLS.
