# ENGAGE: Affect — Baseline collection effects

When the adversary is collecting from an environment, Affect activities that
degrade or deny that collection are preferred over destroy if the same outcome
can be achieved at lower signature.

Match the effect to the collection path you can actually reach. If the only
observed hostile activity is unauthenticated exfil ingestion, start with
degrade or deny on that ingest path rather than a broader disrupt of the
hosting network.
