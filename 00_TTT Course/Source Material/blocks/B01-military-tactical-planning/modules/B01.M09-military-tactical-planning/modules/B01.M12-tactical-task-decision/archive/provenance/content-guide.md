# Tactical-Task Decision Scenario

This Module was previously an embedded exercise in [B01.M09 Military Tactical Planning](../B01.M09-military-tactical-planning/content-guide.md). Complete it in sequence immediately after that lecture.

### Slide 7: Tactical Task Decision Scenario

- Five port-terminal workstations are communicating with an external C2 server
- A hard block may trigger a dormant mechanism that wipes the port database
- Identify the most appropriate tactical task and state its purpose
- Explain why plausible alternatives are less suitable

**Instructor Notes:**

- **Image Prompt:** A simple port network diagram showing five terminal workstations, an external C2 node, and a database with a wipe-risk warning.
- **Say:** "The technical action is not the tactical task. Choose the task that best expresses the required effect while accounting for the adversary's likely reaction."
- **Show:** The scenario and the tactical-task reference.
- **Do:** Give teams **10 minutes**, then ask each for one task-purpose statement. Grade the reasoning, not agreement on one verb.
