# Framework-to-Tactical-Task Synthesis — Instructor Answer Key

## Objective and starting context

Teams fill tactical-task cells and clean up earlier products. Source: the synthesis deck's mission line, worked table, five-log fill-in table, risk chart, and cleanup list. Task names for the blank cells are generated from the deck's own task lists because those cells are empty. See also the nested callback key.

## Expected product

A briefed table plus a cleanup pass: SALUTE, DRAW-D, OCOKA-W, exploitation plan, sub-techniques, risk bands, Navigator layer, and D3FEND graph.

## Acceptable answers

Worked shape the deck already prints:

- T1078 Valid Accounts. Defend starter: script analysis. Engage: EAC0005 lures. Goal Expose. Effect: high-fidelity alert. Risk: very low.
- T1059. Defend starter: script analysis. Engage: EAC0014. Goal Affect. Effect: degrade the workflow. Risk: low.
- T1021. Defend starter: network isolation. Engage: EAC0020. Goal Elicit. Effect: capture TTPs. Risk: moderate spillover.

Risk: use the probability-and-consequence chart. High risk is extreme consequence and likely occurrence. A lure with very low risk stays in the low band. Isolation that can spill is moderate, not automatic high.

Cleanup fails if every confidence is high, if T1059 is used where T1059.001 is justified, or if the Navigator layer depends on packet capture the unit does not have.

## Grading checkpoints

- Accept: doctrinal tasks in the task cells, a goal and a risk band, and one cleanup fix the team can show.
- Do not accept: a tool name in a tactical-task cell.
