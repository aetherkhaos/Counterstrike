# Identifying Exploitable Vulnerabilities:
- service versions from nmap
- vuln scripts in nmap
- the searchsploit command
- blogs and writeups
- Vendor-Provided/Community Proof of Concepts (PoCs) - may require modification
### Tips:
- when searching for an exploit, search for both the CVE and the service version. results from either dont necessarily match.
- read through the pull requests in github, some copies of  exploits are more stable than others, and in some cases, may support additional versions. (check the commits for each branch)
- # TEST YOUR EXPLOIT!
