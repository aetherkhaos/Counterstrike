# Framework Mapping Callback

This Module was previously an embedded exercise in [B01.M31 Framework-to-Tactical-Task Synthesis](../B01.M31-framework-tactical-task-synthesis/content-guide.md). Complete it in sequence immediately after that lecture.

### Slide 2: Exercise — Mapping Frameworks to Tactical Tasks

- Each team takes:
  - The tactical-task handout from B01.M09
  - Their Navigator layer from B01.M19
  - The paired-option worksheet from B01.M23
  - Their D3FEND CAD graph from B01.M28
- For each tactical task verdict (applies / applies with modification / does not apply), map:
  - The ATT&CK technique(s) that a commander might assign that task against
  - The D3 option(s) that would execute that task in blue-space
  - The EAC option(s) that would execute that task through engagement
- Output: a single-page table per team; handoff artifact for B01.M36

**Instructor Notes:**

- **Image Prompt:** A four-column table template. Columns: "Tactical Task", "ATT&CK Techniques (adversary side)", "D3 Options (response)", "EAC Options (engagement)". One sample row filled in, e.g., *Interdict* → *T1071 Application Layer Protocol* → *D3-NTA Network Traffic Analysis* → *EAC0016 Network Manipulation*.
- **Say:** "This is the exercise promised in B01.M09. Take your tactical-task verdicts and wire them into the frameworks you now know. You will not fill out every row—some tactical tasks still do not translate, and that is a valid verdict."
- **Show:** The four-column template with the sample row on the projector.
- **Do:** Timebox: **25 minutes** team work + **5 minutes per team** to back-brief one row of their table. Keep the tables — they become the reference sheet each team carries into the Scenario Brief.
